# React.js Projects

A collection of React.js projects built while learning core React concepts through hands-on practice. Each project focuses on different aspects of React development, ranging from state management to building complete user interfaces.

## 📂 Projects

### 1. Context API

A React application demonstrating state management using the Context API to eliminate prop drilling and share data efficiently across components.

#### Features
- Context API implementation
- Global state management
- useContext Hook
- useState & useRef Hooks
- Component communication
- Clean and reusable component structure

**Tech Stack**
- React.js
- JavaScript (ES6+)
- CSS
- Vite

---

### 2. IMDb Cloning

A responsive clone of the IMDb website built using React. The project recreates the movie browsing experience with a modern UI and component-based architecture.

#### Features
- Responsive homepage
- Movie cards layout
- Navigation bar
- Search interface
- Component-based design
- Clean UI inspired by IMDb

**Tech Stack**
- React.js
- JavaScript (ES6+)
- CSS
- Vite

---

### 3. To-Do List

A simple and interactive task management application that helps users add, complete, and manage daily tasks.

#### Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Dynamic rendering
- State management using React Hooks
- Responsive interface

**Tech Stack**
- React.js
- JavaScript (ES6+)
- CSS
- Vite

---

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Rachita-R/React.js_projects.git
```

Navigate to any project

```bash
cd context
```

or

```bash
cd imdb-cloning
```

or

```bash
cd to_do-app
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
